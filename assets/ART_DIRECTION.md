# Starlink Duo 아트 디렉션

## 공통 원칙

- 짙은 네이비 UI 위에서 48px 축소 상태로도 역할 실루엣이 구분되어야 한다.
- P1 수호자는 청록·강철색과 넓은 에너지 방패, P2 기술자는 주황·차콜과 수리 드론으로 구분한다.
- 색상만 의존하지 않고 장비 형태, 자세, 보조 오브젝트를 함께 사용한다.
- 기존 유명 SF 프랜차이즈의 로고, 의상, 기체 실루엣을 모사하지 않는다.

## 생성 자산과 프롬프트

2026-09-02 Codex 기본 내장 `imagegen`으로 생성했다.

- `icon/starlink-duo-icon-source.png`: 두 미래형 기체의 청록·주황 궤적이 중앙 별 주위에서 S형 연결을 이루는 정사각형 Android 게임 아이콘. 텍스트, 워터마크, 외부 프랜차이즈 요소 제외.
- `art/guardian-portrait.png`: 투명 배경, 허리 위 구도, 얼굴이 보이는 수호자와 넓은 청록 에너지 방패. 친근하고 신뢰감 있는 프리미엄 2D 모바일 게임 렌더링.
- `art/engineer-portrait.png`: 투명 배경, 허리 위 구도, 얼굴이 보이는 기술자와 주황 홀로그램 손목 도구 및 소형 수리 드론. 수호자와 동일한 렌더링 계열.

원본 PNG는 RGBA이며 UI에서는 종횡비를 유지하고 선형 밉맵 필터를 적용한다.
