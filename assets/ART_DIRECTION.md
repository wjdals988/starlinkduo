# Starlink Duo 아트 디렉션

## 공통 원칙

- 짙은 네이비 UI 위에서 48px 축소 상태로도 역할 실루엣이 구분되어야 한다.
- P1 수호자는 청록·강철색과 넓은 에너지 방패, P2 기술자는 주황·차콜과 수리 드론으로 구분한다.
- 해커는 보라·인디고와 홀로그램 코드 격자, 강습병은 진홍·그래파이트와 낮춘 에너지 카빈으로 구분한다.
- 색상만 의존하지 않고 장비 형태, 자세, 보조 오브젝트를 함께 사용한다.
- 기존 유명 SF 프랜차이즈의 로고, 의상, 기체 실루엣을 모사하지 않는다.

## UI V2 원칙

- 전투 중에는 6개 기능 탭을 노출하지 않고 하나의 함선 메뉴로 접는다.
- 시선 순서는 적과 의도, 선택 카드, 남은 에너지, 행동 확정 순으로 고정한다.
- 전투 배경은 분위기를 만들되 상단 14%와 하단 32%의 HUD 가독성을 방해하지 않는다.
- 손패는 겹침을 허용해 카드 묶음처럼 보이게 하고 선택 카드는 크기·테두리·상태 문구를 함께 변화시킨다.
- 모달은 외곽 여백을 유지하여 전투 맥락이 남도록 하고, 닫기 동작을 우측 상단에 고정한다.
- 비전투 화면의 세로 콘텐츠는 축소하지 않고 스크롤하며, 현재 위치는 스크롤바와 `현재` 마커로 표시한다.
- 빈 상태는 오류 문장 하나로 끝내지 않고 조건, 해결 순서, 다음 행동을 하나의 안내 패널로 제공한다.
- 모션·진동·발광은 기기별 설정으로 분리하고 모션을 줄여도 선택 상태 정보는 유지한다.

원본 PNG는 RGBA이며 UI에서는 종횡비를 유지하고 선형 밉맵 필터를 적용한다.
