## 화면별 적용 원칙

1. 전투 화면은 캐릭터-위협-캐릭터의 3열 구도를 고정하고 가장 중요한 체력·행동 상태를 중앙선에 둔다.
2. 협동은 청록, P1은 파랑, P2는 주황, 위험·대전은 적색을 사용하되 모든 상태를 텍스트로도 표시한다.
3. 카드에는 비용, 등급 기호, 이름, 효과 수치를 항상 동시에 보여준다.
4. 상대 계획은 양쪽 확정 전 UI에서 공개하지 않고, 준비 상태만 표시한다.
5. 협동 성장 재화가 대전 승률에 영향을 주지 않도록 대전은 표준 8장 덱과 36 내구도로 시작한다.
6. 항로·편성·상점처럼 현재 모드에서 사용할 수 없는 기능은 무반응으로 두지 않고 이유와 복귀 경로를 제공한다.

## 비판적 판정

- 현재 2400×1080 emulator-5556에서는 6개 상단 탭, 5장 손패, 3열 전투 정보가 겹치지 않는다.
- 해커·강습병을 포함한 4개 캐릭터는 색과 실루엣이 구분되지만 카드별 시각 자산이 없어 상용 카드 게임 수준에는 미달한다.
- Bluetooth 전송과 루프백 상태 동기화는 구현됐지만 실제 2대의 연결 실패·권한 거부·앱 백그라운드 복귀는 아직 출시 판정 근거가 없다.

기존 비교표의 카드·아이템 개수는 콘텐츠 범위 검증에는 유효하지만 화면 품질의 근거로 사용하지 않는다. V2부터 다음 8개 항목을 각각 실제 emulator 캡처로 평가한다.

| 항목 | 배점 | 합격 기준 |
|---|---:|---|

| 시각적 정보 위계 | 15 | 적 의도 → 손패 → 에너지 → 행동 확정 순서가 분명함 |
| 카드 정체성과 가독성 | 15 | 비용, 등급, 이름, 효과, 선택 상태를 축소 화면에서도 구분함 |

| 전투 상태 인지 | 10 | 체력, 적 의도, 준비 여부를 전투 화면 이탈 없이 확인함 |
| 2인 역할 인지 | 10 | P1/P2를 색상 외 초상, 슬롯 문자, 상태 문구로도 구분함 |
| 접근성과 오류 예방 | 10 | 작은 텍스트 4.5:1 대비 목표, 비활성 상태 및 이유를 노출함 |

### 2026-09-02 V2 구현 판정

- 상단 6개 탭을 단일 `함선 메뉴`로 통합해 전투 중 경쟁 요소를 6개에서 1개로 줄였다.
- 16:9 전투 배경, 좌우 캐릭터 스탠딩, 중앙 적 플랫폼을 도입했다.
- 손패에 비용·등급·카드명·효과의 계층과 카드별 기하학 모티프를 추가했다.
- 선택 카드는 기본 166×132에서 178×148로 확대되고, 테두리 2px→4px와 `선택됨` 문구가 함께 변한다.
- 에너지와 행동 확정을 하단 우측의 독립 요소로 배치했다.
- 현재 V2는 전투·공통 내비게이션의 1차 개편이며, 항로·보상·상점의 전용 시각 컴포넌트와 실제 Galaxy 2대 접근성 검증은 후속 게이트다.
- 2차 개편에서 항로를 세로 스크롤형 8구간 목록으로 변경하고 현재 구간을 문자와 청록 마커로 병기했다.
- 편성은 P1/P2 현재 초상과 4직업 선택지를 한 행에서 비교하며, 비활성 선택지는 낮은 명도와 테두리로 구분한다.
- 보상·상점은 전투 카드 컴포넌트를 재사용해 비용·등급·이름·효과 위치가 화면마다 바뀌지 않도록 했다.
- Bluetooth는 3단계 진행 표시와 비행기 모드·권한·페어링별 해결 안내를 제공한다.
- 모션 줄이기·진동·발광 설정은 `user://accessibility.cfg`에 기기별 저장하며 emulator-5556 재실행 후 유지됨을 확인했다.
- 실제 엘리트 전투를 5턴 진행해 전투 승리, 카드 3택, 카드 획득, 다음 항로, 이벤트 선택과 해결 화면을 연속 검증했다.
- 실기동에서 발견한 중복 카드 3택을 수정해 보상과 상점의 한 화면 카드 ID가 모두 고유하도록 보장했다.
- 결과 화면은 팀 내구도·항로 진행·양쪽 크레딧을 표시하며, 카드 보상이 없는 이벤트 결과에서는 보상 CTA를 숨긴다.
- 상점 카드·유물·소비품은 구매 즉시 `판매 완료`로 잠기며 구매 상태는 체크포인트와 같은 상점 방문에 유지된다.
- 카드 제거는 4열 덱 비교, 단일 카드 미리보기, 비가역 경고와 별도 확정 CTA의 2단계 흐름으로 구현했다.
- 보스 진입은 팀 내구도·열쇠·양쪽 크레딧과 준비 안내를 먼저 보여준 뒤 교전 CTA를 제공한다.
- 카드 효과를 공격=적색 조준선, 방어=청색 방패, 회복=녹색 십자, 에너지=황색 번개로 구분하고 효과 태그를 문자로 병기했다.
- 키보드·스위치 접근 시 4px 백색 포커스 링을 표시하고, 모달이 열리면 배경 전투 컨트롤을 포커스 순서에서 제외한다.
- 모달 진입은 닫기→첫 행동 순서로 이동하며 Android 뒤로가기 입력으로 모달을 닫고 기존 포커스로 복귀한다.
- emulator-5556에서는 단일 Back 입력이 두 번 전달되는 경우도 확인해 같은 프레임의 중복 요청을 무시하고 앱 종료를 방지했다.
- 큰 글씨 모드는 핵심 레이블·버튼·카드 문구를 115% 확대하고 동적으로 다시 생성되는 손패와 모달에도 같은 배율을 적용한다.
- 선택한 카드는 행동 큐에 순번·카드명·대상을 실제 해결 순서대로 표시하고, 총비용과 지원 카드 사용량을 같은 상태 바에서 확인한다.
- 행동 확정 CTA에 선택 장수를 병기하고, 선택 직후 하단 상세에 효과·대상·속도를 표시해 확정 전 오류를 발견할 수 있게 했다.
- emulator-5556의 2400×1080 화면에서 115% 큰 글씨와 카드 2장 행동 큐를 동시에 적용해 잘림·겹침이 없음을 캡처로 확인했다.
- Android 가상 접근성 브리지를 추가해 emulator-5556 전투 화면에서 버튼 7개와 핵심 상태 텍스트 10개를 개별 노드로 노출한다.
- 함선 메뉴에서는 배경 전투 노드를 제거하고 제목·안내 2개와 현재 조작 8개만 노출해 스크린리더 포커스가 배경으로 이탈하지 않는다.
- UIAutomator2가 `닫기` 의미 레이블을 조회하고 가상 노드 `ACTION_CLICK`으로 실제 Godot 모달을 닫는 왕복 동작을 검증했다.
- 투명 접근성 레이어를 최상단에 배치한 상태에서도 일반 카드 선택과 함선 메뉴 터치가 모두 통과함을 emulator-5556에서 확인했다.
- 행동 해결 시 선택 카드명을 실행 순서대로 중앙에 공개하고 공격·방어·회복·에너지의 대표 색을 적용한다. 해결 중에는 카드와 확정 입력을 잠그며, `모션 줄이기`에서는 이동·피격 흔들림 없이 0.55초 결과 요약만 표시한다.
- emulator-5556의 실제 협동 턴에서 TURN 01→02, 적 내구도 44→31, 팀 내구도 70→61을 확인했다. 로컬 `궤도 타격` 7과 동료 행동 6이 합산된 13 피해 및 적 공격 9가 UI 결과와 상태 트리에 동일하게 반영됐다.
- 전투 연출 종료 후 행동 확정은 선택 0장·비활성 상태로 복귀해 연속 탭에 의한 중복 제출을 허용하지 않는다. 실행 영상은 `artifacts/emulator-5556-resolution-v2.mp4`로 보존한다.

### 2026-09-03 중앙 적 캐릭터 개편

- 기존 중앙 적은 약 160px 절차적 표식만 표시해 좌우 아군 일러스트와 시각 완성도 차이가 컸다. 1024×1536 RGBA 적 컷아웃을 추가하고 후광·캐릭터·의도 배지의 3단 깊이로 재구성했다.
- 1차 emulator-5556 캡처에서 적 점유율이 낮다고 판정해 캐릭터 표시 영역을 약 30% 확대했다. 최종 2400×1080 화면에서 체력 게이지·의도 배지·좌우 캐릭터와 겹침 없이 중앙 플랫폼을 점유한다.
- 적 의도는 단순 문자열에서 외곽선 배지로 변경했다. 기본 공격은 황색, 18 이상 고위험 공격은 적색 테두리와 문자로 함께 구분한다.
- 공격 해결 후 TURN 01→02, 적 내구도 44→31, 팀 내구도 70→61 상태 전이를 다시 확인해 새 TextureRect 대상의 피격 연출이 기존 판정 흐름을 막지 않음을 검증했다.
- 생성 자산의 최종 프롬프트는 투명 배경, 단일 부유 기계 전투체, 남색 건메탈·자홍 코어·금색 포인트, 260×150 축소 가독성, 텍스트·UI·워터마크 금지를 명시했다.

### 2026-09-03 카드 아트 1차 개편

- 기존 손패의 24px 빈 공간과 절차적 기호를 공격·방어·회복·에너지 4종의 512×512 SF 아트로 교체했다.
- 카드의 모든 효과를 우선순위로 검사해 대표 아트를 선택하므로 첫 효과가 보조 효과인 복합 카드도 공격·방어·회복·에너지 역할을 일관되게 표시한다.
- 같은 `CardButton`을 사용하는 손패·카드 보상·상점·카드 제거 미리보기에 별도 화면별 분기 없이 동일한 아트를 적용한다.
- 115% 큰 글씨가 저장된 emulator-5556의 2400×1080 정지 화면에서 5장 손패의 비용·등급·아트·이름·효과·조작 문구가 카드 경계 안에 표시됨을 확인했다.
- 녹화 증적은 사용하지 않았다. 정지 화면 `artifacts/emulator-5556-card-art-v2.png`와 접근성 트리 `artifacts/emulator-5556-card-art-v2.xml`에서 버튼 7개·핵심 텍스트 10개 노출이 유지됨을 확인했다.

### 2026-09-03 P1/P2 준비 상태 개편

- 양쪽 초상 뒤에 상태 링을 배치하고 대기·로컬 선택·계획 중·확정 완료를 링 진행량 34%·68%·82%·100%, 상태점 1·1·2·3개로 구분한다.
- 초상 하단 배지는 `내 선택`, `계획 N장`, `확정 완료`, `상대 선택 중`을 직접 표시한다. 기존 에너지·방어·유물·상태 문구는 그대로 유지해 링이나 색상을 해석하지 못해도 같은 정보를 확인할 수 있다.
- emulator-5556의 2400×1080 정지 화면에서 카드 선택 전후 `내 선택`→`계획 1장`, 에너지 3→2, 확정 CTA 비활성→활성 전환을 확인했다. 증적은 `artifacts/emulator-5556-player-status-v2.png`와 `artifacts/emulator-5556-player-status-planning-v1.png`이다.
- 두 상태의 접근성 트리는 각각 버튼 7개·핵심 텍스트 10개·전체 노드 25개로 동일했다. 별도 녹화 증적은 생성하지 않았다.

### 2026-09-03 적 등급별 실루엣 개편

- 훈련 전투의 기존 4날 부유체와 별도로 일반=청록 삼각 정찰기, 정예=주황 육각 중장갑, 보스=붉은 왕관형 다중 날개, 진 최종 보스=항성을 삼키는 비대칭 초승달 포식체를 적용했다.
